# Design Language

Avoid looking like Instagram.

Do not reinvent navigation.

Instead reinvent the visual language.

Use:

warm whites

deep navy

aluminum gray

soft sky blue

minimal shadows

large rounded cards

beautiful typography

large aircraft photography

Use custom aviation-inspired iconography whenever possible.

Aircraft photography should dominate the interface.

Reduce unnecessary chrome.

Whitespace is a feature.

Every screen should feel calm.

Borrow inspiration from:

Apple Photos

Flighty

Rivian

Porsche

Garmin

Linear

Do NOT copy Instagram colors or iconography.
